Got Questions?

Frequently Asked Questions

Does Eta really work without an active internet connection? ▼
Yes! Eta is engineered with an offline-first architecture. All your products, customer ledgers, sales records, and inventory data live in a local Room SQLite database on your device. You can record sales, add products, and manage credit without a SIM card or WiFi.
How does voice billing work offline? ▼
Eta leverages on-device speech recognizers combined with an offline fuzzy intent parser. It understands everyday Indian retail phrasing in Hindi, Tamil, Bengali, and English (e.g., "500 rupay ki chini Ramesh ke khate mein") and maps it to your product catalog in milliseconds.
What happens if I lose or change my phone? ▼
Eta includes an instant Local Database Export feature under Sync & Backup. In 1 tap, you can export your entire store ledger into a portable JSON backup file and send it directly to your personal WhatsApp or Google Drive. Restoring on a new device takes seconds.
How does Eta perform in noisy store environments? ▼
Eta is built for loud retail counters. In addition to speech recognition, the interface includes 1-tap quick command chips (e.g. "₹500 Ramesh", "Add 5kg Rice") and an instant 1-tap switch to the Manual POS Cart so billing never stalls during noisy rush hours.
Can multiple staff members use Eta simultaneously in one shop? ▼
Eta operates on a single counter terminal with zero lag. For larger stores with multiple clerks, Eta's cloud deployment sync allows secondary devices to link with conflict-free data replication.
How do I receive updates if I install via direct APK? ▼
Eta features a built-in version verification check in Offline & Cloud Sync. When a new version is released, you can install the update without losing any existing SQLite database records.
Which Android versions are supported? ▼
Eta supports any Android device running Android 8.0 (Oreo) through Android 15. The APK footprint is only 18.1 MB and operates smoothly on entry-level smartphones with 2GB RAM.
